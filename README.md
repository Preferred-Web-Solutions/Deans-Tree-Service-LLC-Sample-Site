# Dean's Tree Service: concept preview

Concept preview by Preferred Web Solutions, not the official website.
Static multi-page site (plain HTML/CSS/JS, no build step) for GitHub Pages, built with the PWS starter kit.
Fonts (Grenze Gotisch and Libre Franklin, SIL OFL) are self-hosted in `assets/fonts`.
Photos are Dean's Tree Service's own, from its public Facebook page, used for this preview. The lettering follows the company trucks; the tree illustration was drawn for this preview.
Map data: U.S. Census Bureau TIGER/Line.
`noindex` and the robots.txt disallow stay on until the owner approves the site and it goes live.
